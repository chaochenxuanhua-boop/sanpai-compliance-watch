# Venture 02: 産廃・建設・運送委託先「全国自治体・行政処分PDF」週次自動名寄せ監視 ＆ ISO14001監査証跡SaaS

工場総務・施設管理・環境安全（EHS）・ISO14001事務局向けに、都道府県・政令指定都市・国土交通省が個別に公表する産業廃棄物処理業および建設・運送関連の行政処分情報（`許可取消`・`事業停止`・`改善命令`・`指名停止`）を名寄せ・検証し、**ブラウザ完結で「産業廃棄物処理委託先 行政処分・許可状況 点検記録票（ISO14001 / 内部統制証跡用）」をA4印刷・PDF保存できるコンプライアンス支援Webアプリケーション**です。

---

## 解決する実務課題（なぜ工場・総務部門が月額課金するのか）

1. **排出事業者責任（廃棄物処理法第12条第5項〜第7項・措置命令連座リスク）**
   - 委託先の産廃収集運搬業者・中間処理業者が「許可取消」や「事業停止」を受けたことに気づかず廃棄物を引き渡すと、排出事業者自身が委託基準違反に問われるリスクがあります。
2. **自治体ごとに分断された公表形式と「欠格要件の連鎖」**
   - 47都道府県・政令市ごとにHTML表やスキャンPDFで別々に公表され、さらに**千葉県で許可取消を受けると、同一事業者が持つ東京都・神奈川県の許可も欠格要件連鎖で順次取り消される**ため、許可番号の「下6桁（全国共通固有番号）」と「13桁国税庁法人番号」による横断名寄せが不可欠です。
3. **ISO14001:2015（箇条8.1 外部提供プロセス管理・9.1 順守評価）の監査証跡作成工数**
   - 毎月手作業で各県のWebページを目視確認しスクリーンショットを貼る作業を、**委託先リストCSVのドラッグ＆ドロップ3秒**で完了し、SHA-256証跡ハッシュ・3段階承認印欄付きのA4点検記録票として出力できます。

## マルチエージェント・パイプライン（`pipeline/sanpai_swarm.py`）

| エージェントクラス | 役割と実装仕様 |
| :--- | :--- |
| **`PrefectureSourceHarvester`** | 全国主要都道府県環境部局・国土交通省ネガティブ情報等検索システム・産廃情報ネットの公式URLレジストリ管理、HTTP `HEAD`/`GET` 死活監視・リンク切れ検知、HTML内の行政処分PDFリンク抽出を実行します。 |
| **`EntityNormalizer`** | ① 旧字体→新字体変換（`髙→高`、`﨑→崎`、`齋→斎`、`發→発` 等）および `㈱`/`(株)`→`株式会社` 正規化、② **国税庁13桁法人番号 Modulo-9 チェックデジット検証アルゴリズム**、③ **10桁/11桁 産業廃棄物処理業統一許可番号の正規化と6桁固有番号抽出**を実行します。 |
| **`DispositionVerifier`** | 処分年月日・停止期間整合性・処分種別（`許可取消`/`事業停止`/`改善命令`/`指名停止`）・公式ドメイン（`.lg.jp`/`.go.jp`/`.or.jp` 等）・産廃品目をクロスチェックし、レコード単位およびデータセット全体のSHA-256ハッシュを付与して `site/data/dispositions.json` を出力します。 |

## ローカル動作確認 ＆ CLI実行手順

### 1. パイプラインの構文チェック・シード検証・単体テスト実行

```powershell
cd c:\Users\tmks0\dev\gemini_auto_web\ventures\02_sanpai_monitor

# Python構文検証
python -m py_compile pipeline/sanpai_swarm.py

# オフライン決定論モードでのデータセット検証・生成
python pipeline/sanpai_swarm.py --verify-seed --dry-run

# 公式自治体ポータルへの実HTTP疎通・リンク死活チェックを行う場合
python pipeline/sanpai_swarm.py --verify-seed --live-check

# 単体テストスイートの実行
python -m unittest discover -s tests -p "test_*.py" -v
```

### 2. Webアプリのローカルプレビュー起動

```powershell
python -m http.server 8090 --directory site
```

ブラウザで `http://localhost:8090` を開き、トップの **「⚡ サンプル委託先CSVで試す（3秒プレビュー）」** をクリックすると、8社分のテストデータ（許可取消・事業停止・旧字体名寄せ一致・他県同一固有番号リスク警告・法人番号チェックデジット誤り・適格）の照合結果とA4点検記録票が即座に表示されます。
